## 4. 残余风险与后续

1. **案例双写**：任务库先写、全局库失败的补偿未实现；当前列表/详情以全局库为准，建议后续加事务或回写。
2. **深链接回退**：URL 删除参数时不会清空旧筛选（只应用存在的参数）；建议后续以 URL 为唯一状态源。
3. **进度弹窗**：页面切换后轮询会继续到终态并清理 store，但“徽标重新打开”在无弹窗实例的页面仍无法恢复 UI。
4. **下载兼容**：立即 revoke 的 Blob 下载在 Chromium 正常，Firefox/Safari 未验证。
5. **错误态**：Tasks/Documents/ReportCenter 失败后依赖 Toast，缺页面级重试。
6. **性能/可用性**：50 万行压测与真实用户 SUS 测试仍未执行（Phase 3 已记录）。
